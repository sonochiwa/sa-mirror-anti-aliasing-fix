Mirror Anti-Aliasing Fix v1.0.0

Renders GTA San Andreas real-time mirrors into a multisampled target and
resolves the result into the game's mirror texture.

Installation:
1. Install an ASI loader for GTA San Andreas US 1.0.
2. Copy MirrorAntiAliasingFix.asi and MirrorAntiAliasingFix.ini next to gta_sa.exe.
3. Start the game.

Set sampleCount to 2, 4, 8 or 16 in MirrorAntiAliasingFix.ini.
Source code: https://github.com/sonochiwa/sa-mirror-anti-aliasing-fix
