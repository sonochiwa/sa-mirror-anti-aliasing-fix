Mirror Anti-Aliasing Fix v1.1.0

Renders GTA San Andreas real-time mirrors at several times their resolution and
reduces the result into the game's mirror texture.

Installation:
1. Install an ASI loader for GTA San Andreas US 1.0.
2. Copy MirrorAntiAliasingFix.asi and MirrorAntiAliasingFix.ini next to gta_sa.exe.
3. Start the game.

Set supersample to 1, 2, 4 or 8 in MirrorAntiAliasingFix.ini. A mirror pass draws
the whole reflected scene, so each step costs four times the pixels.
Source code: https://github.com/sonochiwa/sa-mirror-anti-aliasing-fix
